# 💖 PetalPromise – A Romantic Bouquet Builder for Couples

## 🌸 About the Project

**PetalPromise** is a romantic web application designed for couples to create and share a personalized flower bouquet with love.
Users can select flowers, choose leaves, write a heartfelt note, and send it to their special someone 💌

---

## ✨ Features

* 🌷 Select up to **3 flowers** from 9 beautiful options
* 🍃 Choose **1 leaf type** from 4 varieties
* 💌 Write a **custom love note**
* 😍 Add romantic **emojis** to your message
* 💾 Save bouquet details (backend integration)
* 🔗 (Optional) Share bouquet with a unique link

---

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/your-username/petal-promise.git
cd petal-promise
```

---

### 2. Install dependencies

#### Client

```
cd client
npm install
```

#### Server

```
cd ../server
npm install
```

---

### 3. Run the project

#### Start backend

```
npm start
```

#### Start frontend

```
cd ../client
npm start
```
